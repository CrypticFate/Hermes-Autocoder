# Phase 10: Live Acceptance and Rollout

Run a seeded owned repository through a real configured model and GitHub. Record
the PR, report, cost and merge observation. Restart during execution/publication
and test a dependent task. Then run one real repository for 48 hours.

Acceptance: no duplicate PRs, lost tasks, unauthorized merges or secret leaks;
accurate reports and working pause/cancel/budgets. Only then enable automatic
enrollment across configured owners. Mark this phase complete only with real
artifacts and elapsed pilot time.
